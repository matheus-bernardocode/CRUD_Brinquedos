# Sistema de Gestão de Brinquedos

## Sobre o projeto

Sistema desenvolvido em PHP e MySQL para gerenciamento de brinquedos de uma loja. O sistema permite cadastrar, visualizar, editar e excluir brinquedos, com informações como nome, categoria, faixa etária, preço e quantidade em estoque.

## Como executar

1. Instale e abra o XAMPP.
2. Inicie o Apache e o MySQL.
3. Coloque a pasta do projeto dentro de:"C:\xampp\htdocs\".
4. Abra o phpMyAdmin em "http://localhost/phpmyadmin".
5. Importe o arquivo "database.sql" para criar o banco de dados.
6. Acesse no navegador:"http://localhost/CRUD_6_8_Brinquedos/".
O sistema estará pronto para ser utilizado, conseguindo cadastrar, editar e excluir os brinquedos.
